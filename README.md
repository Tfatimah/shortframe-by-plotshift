# ShortFrame by PlotShift

A mobile-first 9:16 visual creator for YouTube Shorts and Reels.

## Features
- Upload a photo or use built-in backgrounds
- Smart 9:16 image fit with crop/fit/blur options
- Optional headline, supporting text, handle and CTA
- Empty text fields are never rendered
- Layout presets: Big Hook, Quote, Top Story, Lower Impact, Neon, Minimal
- Quick filters: Original, Bright, Warm, Moody, Sepia
- Text color and readability controls
- 1080×1920 PNG export
- Last 2 generated images kept only in the current browser session
- No account, backend, database or permanent image storage

## Privacy
Images are processed locally in the browser and are not uploaded by this version.

## Deployment
This repository is static and Netlify-ready. Use no build command and publish from the repository root.

Built as an extensible first version so future iterations can add templates, branding, paid features, AI assistance or mobile packaging.
